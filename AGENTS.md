# AGENTS.md

## Scope
- Windows XP themed Automata theory case studies showcase (`mark-siazon/Automata-Case-Studies-WinXP_Theme`, branch `main`).
- Follow root `C:\Codes Local\AGENTS.md` first, then this file.

## Environment / Stack
- Astro 7 + React 19 + Tailwind CSS v4 + GSAP, Node `>=22.23.4`, npm (`package-lock.json`).

## Key Commands
- `npm run dev` — start Astro dev server
- `npm run build` — build production site
- `npm run preview` — preview production build
- `npm run astro` — run Astro CLI subcommands

## Verification
- Run `npm run build` after meaningful UI or content changes and inspect `git status -sb`.
